# Hotkeys

Every hotkey in TNF Tools is global: it works while an EVE client has focus. All of them can be
changed or cleared.

To set one, choose **Record** (or **Change**), press the key, then tick **Ctrl**, **Alt** or
**Shift** as needed.

| Hotkey | Default | What it does | Where to set it |
|---|---|---|---|
| **Slot hotkey** (one per preview) | not set | Brings that character's client to the front | Preview → Preview slots |
| **Cycle next** | not set | Jumps to the next enabled preview slot, in slot order | Preview → Settings |
| **Cycle previous** | not set | Jumps to the previous enabled slot | Preview → Settings |
| **Suspend / resume previews** | not set | Releases or restores every thumbnail | Preview → Settings |
| **Next alerting character** | Ctrl+Shift+N | Jumps to the client with the most urgent alert | Preview → Overlays |
| **Toggle click-through** | not set | Makes the previews ignore the mouse, or respond to it again | Preview → Overlays |
| **Move KPI cards** | Ctrl+Shift+K | Unlocks the in-game KPI cards so they can be dragged; press again to lock | Shown on DPS → Characters |
| **Capture Local** *(Intel)* | not set | Takes the Local list you just copied, and says why if it was rejected | Intel → Settings |
| **Add note** *(Intel)* | not set | Starts a note | Intel → Settings |

## Mouse

| Action | Where | Result |
|---|---|---|
| Click | A preview | Focus that client |
| Hold, then drag | A preview | Move it. The hold time is under Preview → Settings |
| Hold near an edge, then drag | A preview | Resize it |
| Right-drag an edge | A preview | Resize every preview together |
| Drag | An unlocked KPI card | Move it |

## If a hotkey does nothing

Another program, or EVE itself, may already be using that combination. Pick a different one.
A hotkey that cannot be registered is skipped; the rest keep working.
